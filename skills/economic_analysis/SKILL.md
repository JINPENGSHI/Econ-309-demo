# Economic analysis skill

A reusable checklist for analyzing economic time-series data:

1. Identify the economic variable, geography, frequency, and units.
2. Retrieve observations from a clearly identified source.
3. Inspect start and end dates; report any missing observations.
4. Calculate changes using a deterministic tool.
5. Distinguish percentage changes from percentage-point changes.
6. Produce a labeled graph and verify the summary against the graph.
7. Cite the source and disclose data limitations.

In this demo, the skill is a *displayed checklist*, not dynamically interpreted by a language model.
